# Ledger

Слои domain, repository/pg, service и app сохранены. Фабрика `ledger.Open(ctx)` возвращает Service, closeFn и ошибку; глобального подключения к БД нет.

Отчёт `GetReportSummary(ctx, from, to)` получает категории через ReportRepository.ListCategories, запускает отдельную горутину на категорию и вызывает SumForPeriod с дочерним контекстом. Рабочие горутины пишут в отдельные элементы среза, результаты объединяются после sync.WaitGroup.Wait. При отмене запроса или ошибке одного работника остальные останавливаются. Heartbeat использует time.Ticker 400 мс и завершается до возврата из расчёта.

Все SQL-операции используют Context-варианты методов. Redis кеширует обычные отчёты на 30 секунд. REPORT_WORK_DELAY=800ms включает отменяемую задержку работников для ручной проверки таймаута; при таком режиме кеш отчёта обходится. По умолчанию REPORT_WORK_DELAY=0s.

Из ledger: `go test ./... -v`, `go vet ./...`. При настроенном C-компиляторе: `go test -race ./...`. Для интеграционных тестов задайте TEST_DATABASE_URL на отдельную мигрированную базу *_test и TEST_REDIS_DB (по умолчанию 14). Тесты очищают тестовые таблицы.
